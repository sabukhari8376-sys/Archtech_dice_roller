🎲 Dice Roller

A simple Python-based Dice Roller application developed as an internship task provided by @Arch Technologies.

📌 Project Overview

This project generates random dice values and allows the user to roll the dice again.

The main focus of the internship task was Python/backend development. As an additional enhancement, I created a simple frontend interface to make the application more interactive and user-friendly.

✨ Features

- 🎲 Roll two dice and generate random values
- 🔄 Roll the dice again
- 🐍 Python backend logic
- 🌐 Simple interactive frontend
- 📱 User-friendly interface
